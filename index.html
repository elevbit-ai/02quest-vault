Como aumentamos a capacidade?

Para caber mais dados na URL, aplicamos Sanitizacao Inteligente antes de salvar:

  • Telefones: Removemos ( ) - e espacos. Salvamos apenas os digitos brutos. O formato visual e reconstruido apenas na leitura. (Economia: ~4 bytes/registro).
  • IDs: Convertemos timestamps gigantes em Base36 (ex: 171562... vira lww6j4p9). (Economia: ~5 bytes/registro).
  • Estrutura: Mantemos Arrays JSON que sao altamente compressiveis pelo GZIP.

Protocolo Hibrido

Continuamos salvando uma copia no LocalStorage para redundancia. Se a URL atingir o limite fisico dos navegadores, seus dados locais permanecem intactos.

Seguranca AES-256
